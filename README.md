# React Counter

Aplicação simples em React para praticar manipulação de estado e lógica condicional a partir de eventos de clique.

[DEMO LINK](https://Igor-hrm.github.io/react_counter-js/)

---

## Sobre o projeto

Este projeto implementa um contador com três botões, cada um responsável por alterar o valor do estado de forma diferente.
O foco é trabalhar **atualização de estado**, **funções reutilizáveis** e **lógica condicional baseada no valor atual do contador**.

---

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- GitHub Pages

---

## Funcionalidades implementadas

- Exibição do valor atual do contador
- Botão **Add 1** para incrementar o contador em 1
- Botão **Add 100** para incrementar o contador em 100
- Botão **Increase** com lógica combinada:
  - adiciona 1 ao contador
  - se o valor final for divisível por 5, adiciona mais 100 automaticamente
